01Sources — the connector contractts/connectors/

Each source is a small connector you drive with your own credentials, so you can only ever index what you're already allowed to read. Live syncs speak the source's own query language.

02Ingest — fetch → normalize → chunk → upsertts/ingest/pipeline.ts

Per-doc transaction, content-hash gated so unchanged docs are no-ops. The cursor advances only on success and holds at the earliest failure. Scope it as tight or wide as you like; deletions tombstone.

ingestDocs() · ingestRepo() upsertDocument · hash-gate --space / --project / --issue / --query --reconcile · tombstone sync_cursors · timestamp / commit-SHA
03Index — one row per doc, one per chunkmigrations/0001–0007

Full-text and vector live side by side on the chunk; the ACL lives on the doc. No pgvector and no server needed — embeddings are packed float32 in bytea, cosine runs in-process, so it works on zero-install PGlite too.

documents(id, source, hierarchy, acl_groups, content_hash, body) chunks.tsv · GENERATED tsvector chunks.embedding · bytea f32 · embed_model ACL: ingested_by = $p OR acl_groups ?| $g
04Search — two passes, fused in-processts/search.ts · core/fusion.ts

The lexical and semantic arms each return a ranking; rrf() fuses them, then tier/recency modifiers and the ACL predicate finish the sort. The vector arm is best-effort — no embeddings or model, and search degrades cleanly to FTS-only.

websearch_to_tsquery · ts_rank cosine · embed_model match rrf({ fts, vec }) modifier(tier, recency) entity route · expand() link graph
05Serve — five MCP tools, two-phasets/tools.ts · mcp-server.ts

A standard stdio MCP server, every call audited. Two-phase by design: search returns ids + snippets, the agent fetches only what it needs — deterministic, and zero tokens spent searching. Hosts can index the tools without spawning via the manifest.

How to read it — left to right

01Sources

Anything you can already read — Confluence, Jira, git repos, notes, logs. You only ever index what you're allowed to see.

02Ingest

Connectors pull with your token and sync incrementally from a saved cursor: edits update, deletions tombstone.

03Index

Each doc is chunked and stored once in plain Postgres — a tsvector and a local vector, behind a fail-closed ACL.

04Search

A query runs two ways at once — exact terms and meaning. rrf() fuses the rankings; tier, recency and ACL finish the sort.

05Serve

Results go out over MCP as five tools — search returns ids + snippets, the agent fetches only what matters. No tokens spent searching.

Signal

Lexical — full-text, exact terms
Semantic — meaning, vendored local model
Fused — reciprocal-rank fusion

Guarantees

Fail-closed ACL on every read path
Deterministic — no LLM in the hot loop
