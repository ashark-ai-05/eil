Confluence, Jira, git repos, notes, logs — each a connector you drive with your own credentials, so you only index what you can already read.

Only what changed. Connectors sync from a saved cursor. Git repos clone, filter by glob (skipping binaries & oversize files), chunk into line-windows, and re-index by git diff — Add / Modify / Delete-tombstone.

Each doc → chunks; every chunk gets a full-text tsvector and a local vector, side by side — no pgvector needed. The ACL lives on the doc.

A query runs two ways at once — exact terms and meaning. rrf() fuses the rankings into one list; tier, recency and ACL finish the sort. Vector arm is best-effort → degrades to FTS-only.

Two calls, deterministic. Search returns ids + snippets; the agent fetches only what it needs — five tools (search_docs · get_doc · expand · search_code · fetch_logs), every call audited, zero tokens spent searching.

Amp, Claude Code, the work connector — any MCP client. They pull ranked, ACL-filtered context and answer grounded. What they ask (and what returns nothing) becomes the signal for the loop below.

Metrics are SQL views over the facts — the vw_* views are the definitions. Recall trend + adoption decide what gets indexed or built next — which feeds back into ingest.
