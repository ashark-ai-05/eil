01 The division of labour the idea, in one sentence

A model is a good estimator and a poor auditor. So it is allowed to estimate, and nothing else. Every number it implies, every rule that follows from that number, and every verdict is computed by a library — and re-checked by a second one that never sees the model.

Why it holds. The thing that judges the work is not the thing that did the work, and it has no model in it — so the same artefact gets the same verdict every time it is checked.

Read the last box carefully. The result is partial. There is no passed in the vocabulary — a phase reports what it did and what it left open, and only a person outside the loop can call it done.

Same input, same refusal, every run. Number 4 is the one that matters most: a citation cannot be invented, because the checker goes back to the document and looks for the words. Number 5 is the line the whole phase exists to draw.

03 Where an answer comes from grounded, or asked

When something is unknown, the pipeline is not allowed to invent it. It works down a fixed order and a person is the last resort, not the first.

1CONTEXT.md repo-localtried first
2ARCHITECTURE.md repo-localtried next
3project docs docs/**tried next
4the knowledge base Confluence · Jira · code, indexedwhere most answers are
5ask a named person blocks the artefactlast resort

Rung 4 is the one that decides whether any of this pays for itself. Rungs 1–3 are whatever somebody wrote down and never revised. Without a real fourth rung the order collapses to "ask a person", and a careful process becomes an expensive way to generate questions.
